# Superseded legal texts (Larry's date rule)
Each file is a version that was replaced on the branch. None of them was ever live in production, so none has an effective date.
- `privacy-a1.md`: §A before memo 21. It was superseded by privacy-a2 (src/content/privacy-a.md) at commit afd97a3.

When a published version is replaced:
1. Copy the old text here as `<version>.md`.
2. Add the date range it was live, in US Central.
3. Bump the `Version:` string in `src/content`.
